[h1]TooltipLib — Changelog[/h1]

Player-facing changelog in plain language. BBCode-formatted so it can be pasted
straight into the Steam Workshop "Change Notes" box on update. For the technical
changelog (root causes, file references), see CHANGELOG.md in the source repo.

[b]v1.5.0[/b]
[list]
[*] Added: tooltip content can now be organized into titled sections. Mods mark where a section starts ("NUTRITION", "CONDITION", ...) and TooltipLib draws the section heading with a divider rule — or, when a tooltip skin is active, hands the skin the exact row positions so it can draw its own section rules and dotted leader lines between labels and values, in its own art style.
[*] Added: mods can now reskin the tooltip box itself. A mod registers a "panel dress" and TooltipLib swaps the flat black rectangle for that mod's textured card — on inventory item tooltips, crafting slot tooltips, and world-object tooltips — while everything written on the tooltip stays exactly where it was. If the skin ever fails (or another mod owns the tooltip panel), the vanilla box comes straight back. First user: Sauce Inventory Rendering's kraft ledger card.
[*] Added: the colored accent line on the tooltip's edge is now a shared channel. Mods declare the color (SauceTooltips' item-type colors, VorpallySauced's upgrade-tier colors) and TooltipLib draws one line — no more two mods painting over each other's bars — and a tooltip skin can pick the color up too (Sauce Inventory Rendering's card tints its title band to match the item).
[/list]

[b]v1.4.2[/b]
[list]
[*] Fixed: tooltips no longer grow taller and taller every frame when another mod takes over the inventory tooltip and draws its own panel (reported with Extensive Health Rework Evolved). We now detect when another mod has fully replaced the tooltip render and step aside instead of stacking our content on top of itself. Other tooltip frameworks (StarlitLibrary, AMS) are unaffected.
[/list]

[b]v1.4.1[/b]
[list]
[*] Fixed: tooltips no longer draw twice when shown from a right-click menu or when hovering an item on the ground. You'd see two stacked tooltip boxes (each with its own colored accent bar); now there's just one. (The game asks the tooltip to draw itself twice per frame — once to measure it, once for real — and we were drawing the colored bits in both passes. We now skip the measure pass.)
[/list]

[b]v1.4.0[/b]
[list]
[*] Added: mods can now place a title/header at the very top of world-object tooltips. SauceTooltips uses this to show the hovered object's name. It has no effect on its own and never makes a tooltip appear by itself — it only shows when a mod also adds tooltip content.
[/list]

[b]v1.3.2[/b]
[list]
[*] Fixed: the "Detail Modifier Key" option can now actually be changed. Before, rebinding it in Mod Options did nothing and it stayed stuck on Shift. (Root cause was a Build 42 bug in the game's own keybind menu — worked around on our side.)
[*] Fixed: the on-tooltip hint now shows the key you actually bound (e.g. "[LAlt] Details") instead of always saying "[Shift] Details".
[*] Fixed: on dedicated servers, turning off "Enable MP Tooltip Sync" now fully stops the tooltip data traffic. Previously it stopped the server replying but clients kept pinging it on every world-object hover, spamming the server console log.
[/list]

[b]v1.3.1[/b]
[list]
[*] Fixed: backpacks and bags show their row of contained-item icons at the bottom of the tooltip again when a tooltip mod is active.
[/list]

[b]v1.3.0[/b]
[list]
[*] Added: a width cap so very long tooltip text wraps neatly instead of stretching across the screen.
[*] Fixed: tooltip values now line up flush against the right edge, even next to long description lines.
[*] Fixed: a crash on certain item tooltips, plus a visible seam when running alongside other tooltip-replacing UI mods.
[/list]

[b]v1.2.0[/b]
[list]
[*] Added: a "Details" hint plus a hold-key to reveal extra tooltip info from mods that support it.
[*] Added: a Mod Options toggle to disable multiplayer tooltip syncing.
[*] Various stability fixes for Build 42.16.
[/list]
